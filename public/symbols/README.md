# Symbol Assets

Place the following PNG files in this directory:

1. `recovery.png` - Recovery symbol
2. `relentless.png` - Relentless symbol
3. `breakaway.png` - Breakaway symbol
4. `chase.png` - Chase symbol
5. `nimble.png` - Nimble symbol
6. `strong_descents.png` - Strong Descents symbol
7. `strong_ascents_6.png` - Strong Ascents symbol (for value 6 cards)
8. `strong_ascents_7.png` - Strong Ascents symbol (for value 7 cards)

These will be displayed at 18x18px on cards.
